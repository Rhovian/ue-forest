# ue-forest

Unreal Engine 5.8 project on macOS, built by coding agents coordinated with [Niles](https://github.com/Rhovian/niles) through UE's native MCP plugin.

1. **Working setup:** agents driving the UE 5.8 editor over MCP under Niles, with Git + LFS.
2. **High-fidelity forest** built on that setup.

Planning happens as a Wayfinder map in this repo's GitHub Issues. Prior research: [docs/research/ue58-mcp-niles.md](docs/research/ue58-mcp-niles.md).
